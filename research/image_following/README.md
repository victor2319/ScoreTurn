# 原谱图像／参考录音跟随路线实测

## 结论

**建议将下一阶段的原型目标调整为：直接显示原谱，稳定判断进入最后一行，
再显示下一页并保留本页最后一行。暂不把完整音符识别作为这一原型的前提。**
这是一条值得验证的路线，还不是可以直接替换正式跟随算法的结论。

CYOLO 预训练模型已经在本地跑通，无需把每页转为 MusicXML。用户提供的
两段钢琴录音均产生了末行候选位置；但缺少人工标注，不能声称候选位置
正确，也不能给出真实录音的定位准确率。仅仅模型能运行不代表演出可靠。

## 图像跟谱：测到了什么

输入：PDF 前两页，及既有的两段钢琴录音（约 32.4 秒、36.0 秒）。模型
每次看到当前页图像、已经到达的音频与递归上下文。**本次固定在第一页，
尚未验证自动翻页后的重新定位**。保留原项目的相邻谱行搜索约束。

- 模型约 138 万参数，checkpoint 5.92 MB（约 5.65 MiB）。
- PDF 两页渲染、二值化、尺寸准备约 0.32～0.40 秒；不包含模型加载。
- 模型加载约 0.95～1.01 秒；这不是手机数据。
- 真实录音每帧计算的中位耗时约 44～57 ms，帧间隔约 50 ms；有超时帧。
  CPU 运行仅接近实时，尚无 Android/iOS 延迟、功耗或发热数据。
- 自带 Kruetzer 合成示例前 20 秒，在排除开头 1 秒后约 96.6% 的帧落在
  标注音符所在的谱行内。这是一个示例、一个页面，不是跨作品准确率。
- 两段真实录音有反向／跨行跳动，尚无时间真值，不能沿用合成结果作保证。

研究用 `LastSystemGate` 要求按谱行顺序、连续约 0.5 秒一致、且音频能量有效。
它不会修改 App 或实际翻页；跳奏／反复需手动重定位。回放结果：

| 测试输入 | 末行候选触发时间 | 是否有准确率真值 |
|---|---:|---|
| 录音 1，使用前 32 秒 | 24.432 秒 | 无，待人工确认 |
| 录音 2，使用前 35 秒 | 28.580 秒 | 无，待人工确认 |
| 静音 5 秒 | 未触发 | 已知不应触发 |
| 无关曲子 32 秒 | 未触发 | 已知不应触发 |

注意：神经网络 objectness 不能直接当匹配概率。静音前 5 秒的平均分数
约 0.62，无关曲子 32 秒平均约 0.43。单独提高置信度门槛不能证明安全。

## 参考录音方案：测到了什么

ScoreFlip 自带四组测试均通过。本次还使用真实钢琴录音作为参考：

- 同一录音经 ffmpeg `atempo=0.8` 保持音高减速后，在线跟踪时间误差中位
  约 24 ms、P90 约 100 ms；这是同一录音变速，不是独立演奏准确率。
- 两段独立录音能够产生对齐轨迹，平均内部 confidence 约 0.35；因没有
  人工时间对应标注，不能计算真实误差。
- **负例失败**：以参考录音的 10 秒、20 秒处作为两个测试翻页标记，输入
  无关曲子时，默认 Follower 在约 4.42 秒从第 0 页跳到了第 2 页。
  这些标记只是测试夹具，不是用户实际翻页位置。说明不能直接把默认安全
  门接入产品；参考录音仍可研究，但需要重新设计无关音频拒绝和跳页限制。

## 下一步判定标准

1. 先人工核对这两段录音真正进入 PDF 第一页最后一行的时间，计算候选误差。
2. 对同一末行触发做慢速、快速、停顿、环境声和无关音乐负例，确认无错翻。
3. 在手机上验证流式推理，达到连续工作且无计算积压；随后再做两页衔接。
4. 以上通过后，才把主流程改成“导入原谱 → 页面布局准备 → 开始监听”。
   OMR 可以保留为可选的小节细化来源；参考录音保留为可选辅助。

## 复现

需要分别 checkout 上述外部项目到固定提交；不要执行 CYOLO 的 setup.py，
它会额外下载整套训练数据，本次推理并不需要训练数据。

本次环境：Python 3.12，PyTorch 2.14.1+cpu，NumPy 1.26.4，OpenCV 4.11，
librosa 0.11，soundfile 0.14，SciPy 1.17，Node.js。本次 torchaudio 仅用于
导入兼容，不调用变速增强路径；评估的变速样本由 ffmpeg 生成。

`evaluate_image.py` 用 checkpoint 保存的滤波器初始化旧 madmom 接口，
随后 strict 加载并逐值核对滤波器；未修改模型权重或重新训练。

```bash
python evaluate_image.py --cyolo /path/cyolo_score_following \
  --page-turner /path/page_turner --audio mono22050.wav \
  --pdf original.pdf --seconds 32 --output local-results.json

# 以下音频都先转换为 24000Hz、单声道、原始 float32 PCM。
node evaluate_reference.mjs /path/scoreflip reference.f32 performance.f32 \
  slowed.f32 unrelated.f32 local-reference-results.json
node negative_control.mjs /path/scoreflip reference.f32 performance.f32 unrelated.f32
python -m unittest test_last_system_gate -v
```

完整汇总指标在 `measurements.json`。输入音频、页图像与逐帧轨迹留在本地，
未提交到 GitHub。所有时间与帧数都注明了实际测试区间。
